# IoT-Based Smart Hydroponic System

## Overview

An IoT-based smart hydroponic system for real-time water quality monitoring, automated nutrient management, and crop yield prediction.

## Key Features

- Real-time pH monitoring
- TDS/EC monitoring
- Turbidity monitoring
- Temperature and humidity monitoring
- IoT cloud dashboard
- Water quality status monitoring
- Automated nutrient management
- Machine-learning-based crop yield prediction

## Hardware

- Raspberry Pi Zero W
- ADS1115 ADC
- pH sensor
- TDS/EC sensor
- Turbidity sensor
- DHT22 sensor
- Nutrient dosing pump

## Technologies

- Python
- Raspberry Pi
- IoT
- Machine Learning
- TagoIO
- Sensor Data Analytics

## System Architecture

Sensors → Raspberry Pi → Data Processing → IoT Dashboard

Historical Hydroponic Data → ML Model → Crop Yield Prediction
